# OIBSIP – Machine Learning Projects

This repository contains the Machine Learning projects completed as part of my **Oasis Infobyte Internship Program (OIBSIP)**. The projects cover classification, regression, data analysis, prediction, and Natural Language Processing using Python and Machine Learning techniques.

## 📌 Projects

### 1. Iris Flower Classification

A Machine Learning classification project that predicts the species of an Iris flower based on its sepal and petal measurements.

**Tech Stack:** Python, pandas, NumPy, matplotlib, seaborn, scikit-learn

**Concepts:** Data preprocessing, EDA, classification, train-test split, model evaluation

---

### 2. Unemployment Analysis with Python

A data analysis and visualization project that explores unemployment trends and analyzes changes in unemployment rates using historical data.

**Tech Stack:** Python, pandas, NumPy, matplotlib, seaborn

**Concepts:** Data cleaning, EDA, data visualization, trend analysis

---

### 3. Car Price Prediction

A Machine Learning regression project that predicts the selling price of cars based on various features such as car characteristics, year, fuel type, and other relevant attributes.

**Tech Stack:** Python, pandas, NumPy, matplotlib, seaborn, scikit-learn

**Concepts:** Data preprocessing, feature engineering, regression, model training, model evaluation

---

### 4. Email Spam Detection

An NLP-based binary classification project that identifies whether an email/message is **Spam or Ham**.

**Tech Stack:** Python, pandas, scikit-learn, NLP

**Concepts:** Text preprocessing, TF-IDF vectorization, classification, Naive Bayes, model evaluation

---

### 5. Advertising Sales Prediction

A regression project that predicts product sales based on advertising expenditure across **TV, Radio, and Newspaper** channels.

**Tech Stack:** Python, pandas, matplotlib, seaborn, scikit-learn, Jupyter Notebook

**Concepts:** EDA, correlation analysis, Linear Regression, Random Forest Regression, MAE, RMSE, R² Score, residual analysis

---
